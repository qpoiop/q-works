# 비용·과금 방어 정책

목표: **일반적인 운영 비용의 1/10 이하**로 유지. 기준점은 "Cloudflare 무료 티어 안에서 동작 → 사실상 $0, 초과 시 조용히 제한(과금 폭탄 없음)".

## 핵심 원칙

1. **무료 티어를 상한으로 사용** — Workers 무료 플랜은 한도 초과 시 요청이 **실패(429)**할 뿐 과금되지 않음. 이게 가장 강력한 과금 방어. 유료 전환 시에도 아래 예산 안에서 무료 포함분으로 커버.
2. **정적 자산은 과금 안 됨** — 앱 셸·아이콘·OG·파비콘은 Workers Static Assets로 서빙(요청 수에 미포함).
3. **모든 쓰기 경로에 상한** — 행 수·크기·빈도 제한으로 D1/R2 무한 증가 차단.

## 예산 기준점 (1/10 목표)

| 리소스 | 무료 티어(일/월) | 우리 목표 상한 | 방어 장치 |
| --- | --- | --- | --- |
| Workers 요청 | 100k/일 | **≤10k/일** | IP당 읽기 120·쓰기 30/분, 인증 8/분 |
| D1 읽기(행) | 5M/일 | **≤500k/일** | bootstrap 쿼리 최소화·인덱스, 알림 LIMIT 50 |
| D1 쓰기(행) | 100k/일 | **≤10k/일** | 쓰기 30/분, 업무 2,000건·알림 200/인·유저 5,000 상한 |
| D1 저장 | 5GB | **≤50MB** | 아바타는 R2로 분리, 만료 세션 자동 정리 |
| R2 저장 | 10GB | **≤100MB** | 아바타 1MB 상한, 256px JPEG(≈2KB), 유저당 1개(덮어쓰기) |
| R2 Class A(쓰기) | 1M/월 | **≤10k/월** | 아바타 업로드 시에만 |
| R2 Class B(읽기) | 10M/월 | **≤100k/월** | **엣지 캐시**로 반복 읽기 차단(immutable+버전 URL) |
| R2 egress | 무료 | — | Cloudflare는 R2 egress 무과금 |
| Rate Limiting 바인딩 | 무료 | — | 과금 없음 |

## 적용된 방어 (코드)

**요청 빈도 (IP당, `worker/security.ts`)**
- 읽기 120/분, 쓰기 30/분 — Rate Limiting 바인딩 + 아이솔레이트 인메모리 이중(바인딩은 근사 집계라 단독 신뢰 금지)
- **인증 8/분** — 로그인/회원가입 전용 강한 제한(무차별 대입·대량 자동가입 방어)

**요청 크기**
- JSON 본문 16KB, 아바타 업로드 1MB(별도 게이트)

**저장 행 수 상한 (D1 무한 증가 방지)**
- 업무 2,000건(전역), 알림 200건/유저(초과분 자동 삭제), **유저 5,000명**
- **만료 세션 자동 정리** — 로그인 시 `waitUntil`로 백그라운드 삭제

**R2 읽기 절감**
- 아바타 GET은 **엣지 캐시(`caches.default`)** — 첫 요청만 R2 접근, 이후 엣지에서 서빙 → Class B op·워커 CPU 급감
- `immutable` 1년 캐시 + 버전 쿼리(`?v=<ts>`)로 변경 시 자동 무효화, 브라우저도 재요청 안 함

**남용·CSRF**
- 변형 요청 Origin/Sec-Fetch-Site 검증, JSON content-type 강제, 메서드 허용목록
- `robots.txt` 전체 차단(크롤러 트래픽 방지)

## 대시보드에서 해야 할 것 (코드 밖 · 권장)

1. **Workers를 무료 플랜 유지** 또는 유료 시 **알림(Notifications) 설정** — 요청/D1/R2 사용량 임계치 알림.
2. Cloudflare **Billing → 사용량 알림**으로 예산 초과 조기 경보.
3. 필요 시 **WAF 규칙**(무료 5개)로 특정 경로·봇 차단 강화.

## 추가로 줄일 여지 (필요 시)

- bootstrap 응답을 유저별 짧은 TTL로 캐시(현재는 no-store로 항상 최신) — 폴링이 잦아지면 도입.
- D1 읽기가 늘면 자주 읽는 팀 로스터·마일스톤을 KV에 캐시.
- 이미지 추가 최적화: WebP 변환(현재 JPEG q0.82, 256px ≈ 2KB로 이미 충분히 작음).
